# Metodologia

O projeto será desenvolvido individualmente utilizando uma metodologia ágil, buscando dividir o desenvolvimento do sistema em pequenas tarefas, que serão organizadas e acompanhadas por meio de um quadro Kanban. O projeto permitirá alterações em seus requisitos e ferramentas ao longo do processo de desenvolvimento, conforme novas necessidades sejam identificadas.

Toda a documentação do projeto será mantida neste repositório.

## Controle de Versão

A ferramenta de controle de versão adotada no projeto é o [Git](https://git-scm.com/), enquanto o [GitHub](https://github.com) será utilizado para hospedagem do repositório e gerenciamento do projeto.
